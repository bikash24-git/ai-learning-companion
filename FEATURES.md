# AI Learning Companion - Features

## Core Features

### 📤 Document Upload
- Support for PDF files
- Support for TXT files
- Automatic format detection
- File size validation
- Instant text extraction

### 📝 Summary Generation
Generate summaries in multiple formats:
- **Short Summary**: 2-3 sentences for quick overview
- **Detailed Summary**: 5-7 sentences for comprehensive understanding
- **Bullet Points**: 5-10 key points for quick review

### 🎴 Flashcard Generator
- Customizable number (5-50 cards)
- Question-Answer format
- Automatic extraction from content
- Expandable card view
- Persistent storage

### ❓ MCQ Generator
- 10 configurable questions
- 4 options each (A, B, C, D)
- Clear answer marking
- Exam-ready format
- Self-assessment capability

### ⭐ Important Questions
- Short Answer Questions (2-4 words)
- Long Answer Questions (paragraph format)
- Exam-Focused Questions (key topics)
- Multi-view display
- Categorized storage

### 💾 Study Materials Repository
- All generated materials in one place
- Organized by type
- Timestamped entries
- Easy retrieval
- Review capability
